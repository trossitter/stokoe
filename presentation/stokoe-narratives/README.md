# Stokoe Notation — Fairy Tale Passages

Open `index.html` in any browser. No server required.

Three fairy tale passages encoded in Stokoe notation (Tab · Dez · Sig).
Goldilocks is sourced from an existing ASL corpus document.
Red Riding Hood and Cinderella are generated from the Stokoe symbol table (Mandel 1993).
Signs marked `vocab ✓` are from the verified training vocabulary. Signs marked `~` are phonologically accurate approximations.

Font: StokoeTempo by Angus Grieve-Smith, Gallaudet University — embedded inline, no internet connection needed.
